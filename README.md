## ✨ Features

- ⚙️ **Fully Automated:** Periodically syncs and builds via **GitHub Actions** (No manual intervention required).
- 🔄 **Smart CDN Resolution:** Automatically scrapes and updates rotating CDN subdomains to keep stream links alive.
- 🎯 **Curated Content:** Filtered premium Bangla and International Movies / Web Series.
- 📺 **Android TV Ready:** Formatted for Android TV players (OTT Navigator, TiviMate, VLC, and Farabi TV App).
- ⚡ **Zero Downtime:** Fast fail-safe logic ensuring your playlist is always playable.
